# Experience Creator with Interface Design

An extended version of the Experience Creator that also designs and builds custom interactive UI components — ideal for science, math, and other hands-on subjects where students benefit from visual tools.

## What to Expect

Like the standard Experience Creator, you'll have a voice conversation about your teaching goals. This version adds an extra step: an Interface Designer agent that creates bespoke React components (simulators, explorers, design tools) matched to your subject matter.

The process:

1. **Interview** — describe your subject, audience, and learning objectives
2. **Design** — the system produces a detailed experience blueprint including component specs
3. **Build components** — custom interactive interfaces are generated and validated
4. **Assemble** — agents, prompts, scenes, and components are wired into a complete experience

Expect the build to take a bit longer than the standard creator (roughly 10–15 minutes) due to the component design step.

## Requirements

This module depends on two templates that will be installed automatically:

- **Tutor Template** — for interactive tutoring with custom component support
- **Lab Template** — for multi-agent lab experiences following the 5E instructional model

## Who Is This For?

Educators and experimenters building experiences where students need to interact with visual tools — simulations, data explorers, design canvases — not just conversation.
