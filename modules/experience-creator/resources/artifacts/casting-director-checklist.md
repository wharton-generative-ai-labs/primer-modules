# Casting Director Checklist

Follow this checklist for every casting job. NOTE that you are customizing an existing template (provided via an artifact). You are inserting your specific customization INTO the content provided and creating a new artifact that also includes your customized character context at the appropriate place. This is essential otherwise only using the character context itself will miss out important instructions for the AI agent playing that character and they won't provide a meaningful experience for students.

- [ ] Retrieve and analyze design document
- [ ] Locate all three CHARACTER CONTEXT blocks
- [ ] Access all three templates
- [ ] For EACH template:
  - [ ] Insert the corresponding context block at [CASTING DIRECTOR, INSERT APPROPRIATE CHARACTER CONTEXT]
  - [ ] Add specific checklist items based on the context
  - [ ] Ensure dialogue matches character personality
  - [ ] Verify learning objectives are addressed
- [ ] Create three properly named artifacts
- [ ] Document process in notes
- [ ] Return artifact IDs to Intake Agent
