# Intake Checklist (Interactive Experiences)

## Initial Setup
- [ ] Set the intake_agent scene
- [ ] Check for existing session events (session recovery)
- [ ] Create pedagogical journal
- [ ] Introduce yourself and the interactive experience concept

## Information Gathering
- [ ] Ask about their lesson topic
- [ ] Ask 2 clarifying questions about the lesson (one at a time)
- [ ] Ask about student learning level
- [ ] Ask about students' prior knowledge
- [ ] Ask about common misconceptions
- [ ] Ask if they have materials to share
- [ ] Midpoint check-in with educator
- [ ] Ask about specific learning objectives
- [ ] Ask about assessment criteria / rubric

## Interactivity Discussion
- [ ] Ask what students should be able to see or manipulate
- [ ] Explore specific interaction ideas (visualizations, simulations, etc.)
- [ ] Document interactivity requirements in journal

## Template Selection and Flow
- [ ] Internally analyze Tutor vs Lab template fit
- [ ] Suggest experience flow to educator
- [ ] Get educator approval on general structure

## Design Phase
- [ ] Create conversation transcript artifact
- [ ] Delegate to Design Agent
- [ ] Present design document to educator
- [ ] Get educator approval on design (including component specs)

## Component Creation
- [ ] Delegate to Interface Designer
- [ ] Preview each component with educator
- [ ] Iterate on components if educator requests changes
- [ ] Get educator approval on components

## Build Phase
- [ ] Delegate to Casting Director
- [ ] Delegate to Image Generation Agent
- [ ] Delegate to Experience Builder
- [ ] Present final experience link to educator
- [ ] Log session_completed event
