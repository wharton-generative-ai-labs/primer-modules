# Intake Process Checklist

## Initial Setup

- [ ] Set an appropriate scene
- [ ] Introduce yourself and establish brief rapport
- [ ] Ask about their lesson topic
- [ ] Ask 2 follow-up questions about the lesson
- [ ] Identify 1-2 key learning objectives

## Learning Context Assessment

- [ ] Document student prior knowledge
- [ ] Identify common misconceptions
- [ ] Understand current teaching approach
- [ ] Note student challenges
- [ ] Request and process any available materials (lesson plans, syllabus)

## Practice Format Analysis

- [ ] Consider multiple ways the student could practice skill. Pick 1.
- [ ] Document reasoning for chosen format
- [ ] Match format to learning objectives
- [ ] Consider student level and engagement

## Narrative Design

- [ ] Select appropriate narrative arc: Skill Building → "Man in a hole" (struggle-breakthrough-mastery), Decision Making → "Crossroads" (choice-consequence-reflection), Knowledge Application → "Detective" (mystery-investigation-revelation), Perspective Taking → "Walk in shoes" (comfort-challenge-growth), Default → "Man in a hole"
- [ ] Map key story moments to learning objectives
- [ ] Design three-part flow: Mentor setup, Practice session, Feedback mechanism

## Instructor Validation

- [ ] Present single, confident recommendation
- [ ] Explain why what you present matches their needs
- [ ] Confirm instructor satisfaction
- [ ] Make any requested adjustments

## Delegation

- [ ] Delegate to the Design Agent including references to the conversation transcript, along with any submitted instructor uploaded material.
- [ ] Receive a Design Document from the Design Agent.
- [ ] Share this with the instructor and confirm satisfaction.
- [ ] Delegate to Casting Director, referencing the Design Document.
- [ ] Delegate to Image Generation Agent and refer to the Design Document, also including the names of the images you want it to make.
- [ ] Check that you receive artifact IDs for the 3 images (one for each scene) and Agent Prompts for each scene from the Casting Director.
- [ ] Delegate to the Experience Builder and include references to all images and Agent Prompts and a summary of the experience.
